One code style, all the way through

Every implementation in this course is written the same way, so the shape of the code becomes a memory aid instead of noise. This is the style, stated once in Chapter 1 and never broken.

  • Guard clause first. if(!root)return; on one line — the base case is the first thing your eye lands on.
  • Helper plus driver. A recursive DFS(...) that carries state in reference parameters, and a small public function that sets that state up. No globals.
  • Reuse the skeleton. Level order, zigzag, left view and right view are the same loop with one line changed. Learn one, get four.
  • Tight spacing, tabs, brace on the same line — the way you actually type under time pressure.
  • Complexity stated on every block, time and space, with the reason in one sentence.
void preorder(TreeNode* root){
	if(!root)return;

	cout<<root->val<<" ";
	preorder(root->left);
	preorder(root->right);
}

Six lines, and three of the four DFS orders are one line-swap away. That is the whole idea.
